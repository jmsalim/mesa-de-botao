# Assets

textures/ and images/: from my own futebol de botao app, Minha Sumula.

sounds/: original sounds synthesized with a Python script (no samples, no third-party recordings).
flick, disc-hit, ball-tap, wall-bounce, net, whistle-start, whistle-foul, whistle-end, crowd-loop, crowd-goal.

Note: textures and the table image were downscaled for phones by `scripts/optimize-assets.py` (originals: commit 2f76ca1). Sounds are used as they are.
